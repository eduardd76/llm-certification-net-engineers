# Syllabus — Network LLM Engineering

## Course objective
Enable a network engineer to understand, build, evaluate, and architect LLM-based systems rather than treating LLMs as black boxes.

## Suggested duration
- Guided course: 24–32 hours
- With GPU experiments and capstone: 40–60 hours
- Advanced extension with own network data: 60+ hours

## Assessment
- Concept quizzes / glossary explanations: 20%
- Hands-on labs: 30%
- Fine-tuning/post-training experiment report: 20%
- Capstone system + evaluation: 30%

## Completion standard
The learner can:
1. Explain the transformer/LLM lifecycle.
2. Choose prompt vs RAG vs fine-tune vs RL/post-training.
3. Build clean datasets with held-out evaluation.
4. Train a LoRA adapter.
5. Explain QLoRA, DPO, GRPO, RLVR, distillation.
6. Build and evaluate a RAG pipeline.
7. Create tool/agent boundaries with deterministic controls.
8. Explain MCP vs A2A.
9. Design an AI NOC with digital-twin verification.
10. Define observability, safety, and release gates.
