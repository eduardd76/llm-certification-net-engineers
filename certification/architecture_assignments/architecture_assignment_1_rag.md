# Architecture Assignment 1 — Network Knowledge and RAG

## Scenario
An enterprise has 10,000 network documents: RFC excerpts, internal runbooks, vendor guides, sanitized incidents, and change procedures.

## Deliverable
Design a retrieval architecture that supports engineers asking operational questions.

Your submission must include:
- ingestion and metadata strategy,
- chunking approach,
- embedding model choice,
- sparse + dense retrieval decision,
- reranking decision,
- citation/grounding approach,
- GraphRAG/topology integration,
- evaluation plan,
- failure handling,
- security considerations.

## Constraint
Current device state is not stored in the document corpus. Explain how live tools fit into the architecture.

## Length
2–4 pages or equivalent diagram + notes.
