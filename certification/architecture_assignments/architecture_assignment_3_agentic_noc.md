# Architecture Assignment 3 — Agentic AI NOC

## Scenario
Build a read-mostly AI NOC that can investigate incidents and propose changes, but cannot change production without approval.

## Deliverable
Include:
- event intake,
- model routing,
- tools,
- state/memory,
- agent loop,
- MCP boundaries,
- A2A boundaries,
- termination conditions,
- human approval,
- policy engine,
- audit/trace model,
- failure/retry behavior.

## Required design choice
Explain when multiple agents are justified and when a single orchestrated agent is better.

## Length
3–5 pages plus architecture diagram.
