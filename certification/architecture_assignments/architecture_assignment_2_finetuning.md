# Architecture Assignment 2 — Network Fine-Tuning Program

## Scenario
You need a local 3B–8B model that classifies incidents, produces structured troubleshooting plans, and uses company terminology.

## Deliverable
Design:
- data sources,
- sanitization,
- SFT schema,
- train/validation/test split,
- LoRA/QLoRA strategy,
- baseline,
- evaluation harness,
- model card,
- release criteria,
- data flywheel.

## Required challenge
Explain why current configurations and live BGP state should not be the primary fine-tuning targets.

## Length
2–4 pages.
