# Architecture Assignment 4 — Digital Twin Assurance Plane

## Scenario
Before an AI-proposed network change is approved, it must be tested in a digital twin.

## Deliverable
Design:
- twin scope and fidelity,
- source-of-truth synchronization,
- representative vs full-fidelity components,
- test generation,
- expected invariants,
- pass/fail criteria,
- rollback plan,
- human approval,
- evidence returned to the AI system.

## Required challenge
Critique the statement: "If 100 servers run the same application version, one representative instance is always enough in the digital twin."

## Length
3–5 pages.
