# Student Certification Checklist

## Before Practical Exam 1
- [ ] I can explain prompt vs RAG vs fine-tuning.
- [ ] I can inspect and split a dataset.
- [ ] I can explain cross-entropy and train/eval loss.
- [ ] I can configure LoRA.
- [ ] I can run held-out evaluation.
- [ ] I can identify overfitting and leakage.

## Before Practical Exam 2
- [ ] I can build read-only tool schemas.
- [ ] I can represent agent state explicitly.
- [ ] I can define termination conditions.
- [ ] I can explain MCP vs A2A.
- [ ] I can detect indirect prompt injection.
- [ ] I can enforce a human approval boundary.

## Before Capstone
- [ ] I have a baseline.
- [ ] I have a golden test set.
- [ ] I have current-state tools.
- [ ] I have deterministic validators.
- [ ] I have at least one failure-injection test.
- [ ] I have a trace/audit design.
- [ ] I have a release decision.
