# Lab 7 — Bounded Network Agent

**Recommended time:** 3 h  
**Points:** 25

Build a read-only troubleshooting workflow with:

- structured incident state,
- at least three tools,
- tool argument validation,
- max-step termination,
- low-confidence escalation,
- malformed-output handling,
- audit trace.

Inject:
- one tool timeout,
- one unknown device,
- one malicious retrieved instruction.

**Deliverable:** runnable notebook and trace for one successful and one failed investigation.


## Grading dimensions

- technical correctness,
- reproducibility,
- evidence discipline,
- evaluation quality,
- safety,
- clarity.
