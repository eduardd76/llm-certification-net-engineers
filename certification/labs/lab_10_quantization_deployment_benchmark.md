# Lab 10 — Quantization and Deployment Benchmark

**Recommended time:** 2 hours  
**Status:** Advanced elective

Choose one small/medium model and compare at least two precisions/quantized variants.

Measure:
- held-out network correctness,
- schema validity,
- RAM/VRAM,
- time to first token,
- tokens/sec,
- cold-start time.

Explain whether the memory saving is worth the quality/latency change.

Do not select a winner using model-file size alone.
