# Lab 8 — AI NOC Assurance and Release Gate

**Recommended time:** 2.5 h  
**Points:** 20

Take an existing Network AI prototype and add:

- deterministic schema validation,
- policy gate,
- digital-twin or graph-based verification,
- human approval boundary,
- rollback/failure path,
- observability trace.

Define five release gates and two stop-ship conditions.

**Deliverable:** architecture diagram + validation notebook + release checklist.


## Grading dimensions

- technical correctness,
- reproducibility,
- evidence discipline,
- evaluation quality,
- safety,
- clarity.
