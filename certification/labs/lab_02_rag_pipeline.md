# Lab 2 — Build and Break a Network RAG Pipeline

**Recommended time:** 2.5 h  
**Points:** 20

Build a small RAG pipeline over networking documents.

Required:
- at least 20 chunks,
- embeddings,
- top-k retrieval,
- source IDs/citations,
- 10 evaluation questions.

Then intentionally create three failures:
- bad chunking,
- missing relevant source,
- irrelevant retrieval.

For each failure, diagnose whether the root cause is retrieval or generation.

**Deliverable:** notebook + retrieval evaluation table.


## Grading dimensions

- technical correctness,
- reproducibility,
- evidence discipline,
- evaluation quality,
- safety,
- clarity.
