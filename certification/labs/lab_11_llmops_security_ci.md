# Lab 11 — LLMOps Security CI Gate

**Recommended time:** 2 hours  
**Status:** Advanced elective

Create a release test suite for a Network AI assistant.

Required gates:
- golden-set correctness,
- retrieval Recall@k,
- schema validation,
- prompt-injection scenario,
- unauthorized tool scenario,
- tool timeout,
- latency SLO.

Make one deliberate regression and demonstrate that CI blocks release.
