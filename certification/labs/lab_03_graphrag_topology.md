# Lab 3 — Topology-Aware Retrieval

**Recommended time:** 2 h  
**Points:** 15

Build a topology graph with devices, interfaces, links, VRFs/VNIs, and one application dependency.

Answer:
- shortest/valid path,
- blast radius of one failed component,
- neighboring dependencies,
- which graph facts should be retrieved before an LLM diagnosis.

**Deliverable:** graph representation + three topology queries + explanation of when graph retrieval beats vector retrieval.


## Grading dimensions

- technical correctness,
- reproducibility,
- evidence discipline,
- evaluation quality,
- safety,
- clarity.
