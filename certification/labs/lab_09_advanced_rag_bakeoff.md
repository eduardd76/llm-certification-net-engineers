# Lab 9 — Advanced RAG Bake-Off

**Recommended time:** 2 hours  
**Status:** Advanced elective

Build a 30+ document network corpus and 15-query evaluation set.

Compare:
1. sparse,
2. dense,
3. hybrid RRF,
4. multi-query + RRF.

Measure Recall@3, MRR, context precision, and answer groundedness.

Then choose one advanced technique:
- HyDE,
- parent-child retrieval,
- contextual compression,
- metadata/self-query filtering.

Your conclusion must identify which query types improved and which regressed.
